# 配图后插与双版本交付

## 文件与顺序

1. `layout_slides/` 保存带准确文字和图片空位的逐页底稿。
2. 全部底稿绘制完成后，先按页序组装 `working/留位底稿.pptx`。
3. 底稿组装完成后，选择、获取或绘制独立配图，保存到 `image_assets/`；已有素材可提前登记来源。
4. 将配图放入对应位置，检查后保存高清完整成图 `final_slides/slide_001.png` 等。
5. 依据同一批最终成图及对象清单，输出纯图片版与可编辑版，两份文件保持文案、图片、页序和备注一致。

## 图片位置清单

`image_slots.json` 用于规划与跟踪后插图片。它与转换用的 `editable_manifest.json` 分别管理；后者依据实际定稿页面定位。

```json
{
  "author": "用户",
  "coordinate_canvas_px": [1920, 1080],
  "slots": [{
    "slide": 7, "slot_id": "p007_case_photo", "box_px": [1040, 240, 760, 600],
    "purpose": "对应本页案例的真实场景照片", "asset_type": "photo",
    "frame": "rect", "fit": "cover", "focal_point": [0.5, 0.5],
    "source_requirement": "用户材料或可核实的原始来源",
    "asset_path": null, "prepared_asset_path": null, "source": null, "status": "planned"
  }]
}
```

页码从1开始，每个位置ID唯一。坐标按 `coordinate_canvas_px` 换算到实际成图尺寸。绘制完成后测量实际空位，修正坐标或页面，保证图片准确落位。`asset_path` 保存原图，`prepared_asset_path` 保存实际裁切或透明补边版本，`source` 保存出处。状态按 `planned`、`inserted`、`verified` 更新。

## 选图与插入

- 图片围绕本页论点选择。真实人物、产品、界面和证据使用用户提供或可核实的素材；概念性插图按用途生成。
- 图表以真实数据制作，保留指标定义、轴、单位和精确标签。
- 空位保留干净底色或统一面板，图片周围文字清晰。`cover` 保持比例裁切，`contain` 完整展示内容；截图和完整图表通常采用 `contain`。
- 按实际显示大小与最终成图密度检查原生像素，保存未经缩小的原素材。裁切还需核对可见区域的像素与信息。
- 可以在底稿PPT中插图后导出完整成图，也可以在底稿已组装后按确定位置合成配图，再组装最终图片版。页面文字在绘图阶段完成。

## 转换与验收

全部必要图片位置核验完成后，按 [可编辑转换规范](editable-conversion.md) 建立对象清单并生成第二份PPT。照片、截图、Logo和复杂插图直接复用已选定素材，保留对象级替换能力；普通文字、简单图形、表格和可还原数据图表形成原生对象。

使用实际办公软件渲染两份完整PPT，逐页检查文字、数据、边界、层级、配图和清晰度。图片版每页是一个完整页面图片；可编辑版按实际对象验证编辑能力。将演讲稿同步到两份PPT备注，检查作者、创建者和最后修改者为“用户”。
