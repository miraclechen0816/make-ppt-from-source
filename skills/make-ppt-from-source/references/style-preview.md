# 五种风格的九宫格预览

## 预览先于正式全稿

资料与基本需求明确后，默认制作 **5 种风格、5 张独立九宫格**。九宫格是供用户选择的真实视觉样张；展示图片后等待用户选择，再绘制正式全稿。当前用户明确调整数量或跳过预览时，按当次要求执行。

选样阶段可以准备内容大纲、预览文案、布局草案与配图位置。完整的逐页提示词和正式成图在风格确定后定稿。已有资料直接用于预览，样张体现这份 PPT 的实际主题与关键内容。

## 同一组九页，覆盖正文能力

五种风格采用相同的九页内容、顺序和信息量，按从左到右、从上到下排列：

| 格位 | 页面作用 | 观察重点 |
|---|---|---|
| 1 | 封面 | 主题、标题层级、视觉气质 |
| 2 | 核心问题或内容导航 | 阅读顺序、章节组织 |
| 3 | 背景与关键观点 | 正文字号、分组和留白 |
| 4 | 结构或流程 | 连接、层级、图形语言 |
| 5 | 关键数据或真实图表 | 数字、轴与单位、强调方式 |
| 6 | 对比、矩阵或表格 | 较密信息的清晰度 |
| 7 | 案例或图文页面 | 图片位置、图文比例 |
| 8 | 结论、建议或行动计划 | 信息收束与重点 |
| 9 | 结尾 | 结束语、结论或交流邀请 |

每张九宫格固定含封面、7 张代表性正文、结尾。根据材料调整中间七页的具体类型；缺少的数据以已核实的信息和合适的页面类型替换。资料或最终页数少于九页时，可以展示真实内容的不同正文布局，并在对话中说明它们是版式样张。

配图样张先保留清洁的图片区域，展示未来插图的位置、比例和周边文字。位置中保持干净底色，与最终留位流程一致。

## 五种风格的实质差异

结合主题、场景和参考资料选择五个合适方向。例如咨询报告、研究年鉴、现代编辑、深色科技和人文书卷。示例用于启发，具体方案根据资料决定。

五个方向至少在字体气质、网格与留白、标题构图、图表语言、色彩和背景材质中形成多项差异。同一方向内部，九页共享稳定的字体层级、间距和图形规则。严格品牌模板下，沿用品牌约束，从布局与信息组织中建立五种区别。

页面采用准确而简短的真实文字，文字随图像一起生成。风格编号、名称及说明在对话中展示；图片内只保留页面内容与有信息作用的标签。角落保持清爽，必要出处按实际阅读需求安排。

## 生成与展示

### 方式一：每种风格直接生成一张九宫格

适合快速对比，默认可采用。逐种调用已获准且可用的图像工具，每张图明确规定 3×3 等大分格、每格的目标画幅、九页准确文案与版式。16:9 的九页组成整体近 16:9 九宫格，请求足够高的原生分辨率，按实际输出验收。

逐格检查封面、七张正文和结尾是否完整，格线是否整齐，文字与信息是否足以辨认。观察到缺格、重复封面、正文同质或文字严重模糊时，针对相应问题修正。

### 方式二：每种风格先生成九张样张，再拼接

适合需要更精确的内容、分格与字体检查的任务。保留九张原图，使用本地工具做缩略拼图，页面文字与视觉内容在原图生成阶段完成。

```powershell
py -3.11 <skill-root>/scripts/make_style_grid.py --out <project>/style_previews/style_01_grid.png <page-01.png> <page-02.png> <page-03.png> <page-04.png> <page-05.png> <page-06.png> <page-07.png> <page-08.png> <page-09.png>
```

脚本要求恰好九个不同文件、统一画幅，按参数顺序排为三行三列，保持比例，输出 PNG，作者与创建者为“用户”。默认单格宽 1280 像素；可用 `--tile-width` 和 `--gutter` 调整缩略图尺寸与间隔。输出路径须为新文件。

### 向用户呈现

分别展示五张实际预览图，配上 A–E 或 1–5 的简短风格名称。每种用一句话说明视觉特点即可，问题聚焦选择编号或组合修改。

保存 `style_previews/style_01_grid.png` 至 `style_05_grid.png` 与 `style_previews/selection.md`，后者记录九格内容、用户的选择、修改意见和正式视觉基准。用户选择混合方案时，将组合后的统一规则写清，必要时补一张合并风格九宫格供确认。

正式页面依据选定方案重新以目标原生分辨率绘制。九宫格缩略图用于选样，正式文件使用完整高清单页。
